# Network Protocols
- Defines rules so that two systems and communicate with each other
- 7 Layers of Network Protocol
  - Application
  - Presentation 
  - Session
  - Transport 
  - Network
  - Data Link
  - Physical

- Application Layer Protocol
  - Client Server Protocol
    - HTTP
    - FTP - Not used. File trnasferred over data connection is not encrypted. We use HTTPS instead
    - SMTP - Used for mails.
    - Web Sockets - Used in messaging apps because we need two way communication
  - Peer 2 peer protocol
    - WebRTC (Uses UDP to transfer data)

- Transport Layer/ Network Layer
  - TCP/IP
    - Single connnection is maintained and data is sent over smaller packets between the vitual connections
    - Ordering of packets is maintained and acknowledgement is sent for each packets received
  - UDP
    - Multiple connections are present and data is sent over smaller packets betweeen connections
    - Ordering of packets is not maintained and they are sent parallelly over multiple connections
    - No acknowledgemnt 
    - It is FAST
    - EXAMPLE - live streaming, video calling
