# Proxy vs Reverse Proxy

## Topics
1. What is proxy server
2. Different Types ?
   1. Forward Proxy
   2. Reverse Proxy
3. Proxy vs VPN
4. Proxy vs Load Balancer
5. Proxy vs Firewall


### Proxy
- Client and Server cant communicate directly
- They coommunicate through proxy server
- Proxy server takes requests from its clients -> sends request to server -> takes response from server -> sends the response to its clients

### Forward Proxy
- Proxy sits in front of client. No server can talk directly to the client. They talk to Proxy only.
- Advantage
  - Provides Anonimity to client - Only the IP address of Proxy server is open and hides the IP of all its clients
  - Provides grouping of request - groups the same requests from different clients together. Brings response to them
  - Provides access to restricted data/content - 
  - Provides Security - it can have rules on what all data can be accessed and not accessed
  - Provides caching - it can cache certain static data in itself
- Disadvantage
  - Works on Application Layer - For each Application we need to setup the proxy

### Reverse Proxy
- No client can directly talk to the server. The Proxy helps hide the IP address of server
- Advantages
  - Provides Security from DDOS attack to servers (Example - CDN)
  - Provides Caching. Helps reducing latency
  - Provides Load balancing. Can help reroute requests to different servers

> Forward proxy sits in front of a client and ensures that no origin server ever communicates directly with that specific client. On the other hand, a reverse proxy sits in front of an origin server and ensures that no client ever communicates directly with that origin server.


### Proxy vs VPN
- There exists a VPN client and VPN tunnel
- VPN creates a VPN tunnel between vpn client and vpn tunnel
- Client data is encrypted in VPN client
- then data is sent over the VPN tunnel. Tunnel helps protect the encrypted data from outside attacks
- data is decrypted at VPN server. 
- VPN server then calls the requested server
> Proxy doesnt provide Encryption/Decryption and only hides the IP address

### Proxy vs Load balancer
- Reverse proxy can act as a Load Balancer
- But Load Balancer cannot be a Proxy
- Load balancer is not required if we have only one server. It is required when we have multiple servers
- But we might need Reverse Proxy if we have one server(becauseo of anonimity, caching, security).

## Proxy vs Firewall
- Firewall has holes with set rules that which data can pass through them
- We can do **Packet Scanning** in Firewall. Check header, ip address of sources and destination
- Proxy runs on Application level. It has acess to data, so based on data as well, we can set rules in Proxy
- Proxy can act as a firewall as well
