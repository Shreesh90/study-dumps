# Load Balancer Algorithms

### Types of Load Balancer
1. Network Load balancer (L4 Balancer)
   1. Static Algorithm
      - Round Robin
      - Weighted Round Robin
      - IP Hash
   2. Dynamic Algorithm
      - Least Connection 
      - Weighted Least Connection
      - Least Response Time
2. Application Load Balancer (L7 Balancer)


### Round Robin
- Advantages:
  - Easy to implement
  - Equal Load distribution to servers
- Disadvantages:
  - Server with high capacity will be underutilized
  - Low capacity server can go down because of overload

### Weighted Round Robin
- Advantages:
  - Easy to implement as weights of each server is static and doest changes
  - Low resource server doesnt gets overloaded
- Disadvantage
  - If low capacity server gets high processing request, it can get overloaded

### IP Hash
- Compute hash for the Client IP Address and then allot the server
- Advantage:
  - easy to implement
  - Good for case when the same client needs to connect to same server every time
- Disadvantage:
  - If client request comes through Proxy, all requests will go to the same server. Overloading the server
  - Equal distribution of requests is not ensured

### Least Connection
- Checks which server has less active connection for reach request. Allot request to the less occupied server
- Advantage:
  - Overloading of server is prevented as dynamic calculation of load on server is done
- Disadvantage
  - TCP connections can remain active but have no traffic
  - No differentiation between low capacity and high capacity server. Low capacity server might get overburdened. 

### Weighted Least Connection
- Calculate the ratio fo Number of Active connection to the Server Weight
- Server with minimum ratio gets the request

### Lease Response Time
- TTFB - Time to first Byte - Time interval between sending the request and receiving the response from the server
- Picks the server which has least value of (Acrive Connection * Least TTFB). If clash happens, follow Round Robin.
