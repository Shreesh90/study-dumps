# CAP Theorem

- Desirable property of Distributed System with replicated Data
- C - Consistensy, A - Availability, P - Partition Tolerance
- All three properties cant be used at once together in any system
- Possible - CA, AP, CP
- Not Possible - CAP

## Note
- Never trade off with Partition Tolerance. Always try to maintain it.
- You can trade off with Consistency or Availability. So available options - CP, AP
