# Symmetric and Asymmetric Encryption

> Can add more details in this doc

## Symmetric Encryption
- Same key is used for both Encryption and Decryption
### Encryption Algorithms
1. DES (Not Recommended)
   - Fixed length key : 56 bits
   - Process data in 64 bits
   - Perform 16 rounds of encryption
2. AES
   - Support key lengths: 128, 192, 256 bits
   - Process data in 128 bits
   - Encryption rounds depends on key size
     - 10 rounds - 128 bit key
     - 12 rounds - 192 bit key
     - 14 rounds - 256 bit key
### Advantage
- Fast and less computation compared to Asymmetric 
- Good for encrypting bulk data

### Disadvantage
- How to securely distribute key between client and server
- If number of client increases, server has to manage those number of symmetric keys in its distribution too

## Asymmetric Encryption
- Uses 2 different keys - Public and Private Key
  - Public Key - used by sender to encrypt
  - Private key - used by receiver to decrypt

### Encryption Algorithms
1. RSA - used 1024 bit key lengrg
2. DSA
3. Diffie-Hellman
4. ECDHE

### Advantage
- No security issue with key distribution
- Provide key exchange protocol like Diffie-Hellman, ECDHE
- Digital signature can be created - helps to authenticate and provide integrity too

### Disadvantage
- Computation intensive compared to symmetric encryption
- Might not be suitable for encrypting bulk data - comparatively slow to symmetric
