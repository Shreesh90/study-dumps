# JWT (JSON Web Token)

- Secure way of transmitting data between parties using JSON object
- THis infomration can be verified because it is digitally signed by RSA(public/private key) etc.

- Advantages:
  - Compact in size. Can be sent in Header and transmits fast due to its size.
  - Payload contains all the information about user. So it is **Stateless**
  - Can be signed using Symmetric(HMAC) or Asymmetric(RSA)
  - Built in expiry mechanism
  - Custom Claim(additionla data) can be added in the JWT
